# Security Policy

## Supported Versions
We actively support and release security fixes for the latest major version of **ai-pr-reviewer**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within **ai-pr-reviewer**, please do **NOT** open a public issue. Instead, report it privately to our security team:

- **Email**: `vecesta.co@gmail.com`
- **Subject**: `[SECURITY VULNERABILITY] ai-pr-reviewer`

Please include:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept diff.
3. Potential impact and attack vectors.
4. Suggested remediation if available.

We will acknowledge receipt within 48 hours and work with you to patch and disclose the issue responsibly.
